# Shelver Classroom Game

This is a standalone browser game for practicing fiction alphabetizing and Dewey Decimal call-number order.

## Publish it so students can open it from Google Classroom

### Option A: GitHub Pages (free)
1. Sign in to GitHub or create an account.
2. Create a new **public** repository named `shelver-game`.
3. Upload `index.html` to the repository's top level and commit the file.
4. Open the repository's **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)` folder, then Save.
7. Wait for GitHub Pages to publish. The public game address will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/shelver-game/`
   Use the exact URL shown in the Pages settings.

### Add it to Google Classroom
1. Open the class in Google Classroom.
2. Select **Classwork → Create → Material** (or **Create → Assignment** if you want students to complete a task).
3. Give it a title such as **Shelver: Practice Library Call Numbers**.
4. Add directions, for example: “Open Shelver. Choose Fiction or Dewey Decimal, complete all three levels, and ask your teacher if you need help.”
5. Click **Add → Link**, paste your published game URL, and add it.
6. Choose the topic and assign/post it.

Students can then open the link from Classroom on a Chromebook, tablet, or computer. The game itself does not collect names, submit scores, or send results to the teacher; students play in their browser.

## Important
- The HTML file must be hosted at a public HTTPS address for students to access it reliably from Classroom. Uploading the file as a Classroom attachment alone does not host it as a playable website.
- Follow your school/district's rules about public hosting and student access. If GitHub is blocked by your district, ask your Google Workspace administrator or technology specialist which approved hosting service to use.
